# RescueNet – Disaster Response Management System
## Java OOP Course Project – Implementation Plan

---

# 1. Project Overview

RescueNet is a simple Java-based Disaster Response Management System.

The purpose of the system is to help manage:

- Disaster events
- Victims
- Rescue teams
- Shelters
- Rescue assignments
- Shelter allocations
- Rescue status
- Reports

The project is designed specifically for Second Year students who are learning Java and OOP for the first time.

The implementation will use only concepts covered in the Java OOP syllabus.

---

# 2. Main Objective

The system should provide a simple way to:

1. Register and manage disaster events.
2. Register victims affected by disasters.
3. Create and manage rescue teams.
4. Manage available shelters.
5. Assign rescue teams to victims.
6. Allocate rescued victims to shelters.
7. Update rescue status.
8. Generate simple reports.
9. Store important information using files/database.
10. Demonstrate Java OOP concepts through the project.

---
